# PLAN-2026-11-03 菜单栏托盘 + 关窗隐藏（F16）

> 存档规则：批准时原文存档、不修改；实施偏差只在文末「事后补记」追加。
> 决策：2026-11-03，用户在 `0.3.0` 之后点名做 F16 / F14；关窗行为早在 2026-11-03 下午已定 **B（关窗隐藏到菜单栏、不退出）**。

## 一、目标

1. 菜单栏常驻一个模板图标（深浅色菜单栏自适应），点击弹出菜单：
   **显示 / 隐藏主窗口 · 在浏览器中打开 · 检查应用更新… · 更新 pi-web… · 打开日志目录 · 退出**
2. **关窗行为改为隐藏**：点窗口关闭按钮 → 窗口隐藏，App 不退出，pi-web 的后台任务继续跑。
3. 隐藏后可从托盘「显示 / 隐藏主窗口」或点 Dock 图标（macOS reopen 事件）唤回。
4. 只有「托盘 → 退出」/ 菜单「退出」/ ⌘Q 才真正退出并清理侧车。

## 二、实现

| 文件 | 改动 |
|---|---|
| `src-tauri/Cargo.toml` | tauri 特性加 `tray-icon`（托盘）与 `image-png`（从字节加载图标） |
| `src-tauri/icons/tray-template.png` | 新图标：36×36（18pt @2x）π 字形，纯黑 + alpha，模板图 |
| `src-tauri/src/tray.rs` | 新建：`create()` 建托盘 + 菜单并复用 `menu::on_event` 的动作；`toggle_main()` 显示/隐藏主窗口 |
| `src-tauri/src/main.rs` | setup 里创建托盘；主窗口 `CloseRequested` → `prevent_close()` + `hide()`；`RunEvent::Reopen` → 唤回窗口 |
| 测试钩子 | `PIWEB_TRAY_PROBE=1`：启动 3 秒后调用 `window.close()`，打一行 `close() 之后 visible=?` 后退出 |

## 三、验收

1. `cargo test` / `npm run smoke` / `npm run smoke:app` 全过（托盘图标不能影响启动）。
2. **关窗探针**：`PIWEB_TRAY_PROBE=1` 启动 → 日志出现
   `[window] 关闭按钮：已隐藏到菜单栏` 与 `[tray-probe] close() 之后 visible=false`，进程此时仍活着。
3. **真机截图**：菜单栏出现 π 模板图标（截图存 `docs/screenshot-tray-icon.png`）。
4. 手动：点关闭 → 窗口消失但 App 还在；托盘「显示 / 隐藏主窗口」可恢复；托盘「退出」后无残留 node 进程。

## 四、风险

- 关窗变隐藏后，用户可能以为"已经退出"——靠托盘图标与 Dock 图标仍在提示；退出入口在托盘/菜单里都标了「退出」。
- 「Dock 图标 → 唤回窗口」依赖 macOS 的 `applicationShouldHandleReopen`（Tauri 的 `RunEvent::Reopen`），夸大点说只验证了事件注册，未逐一验证所有唤回路径（见事后补记）。
