## 回归修复（2026-11-01 晚，用户实测反馈）

**症状**：把终端里的 `npx @agegr/pi-web` 结束掉 → 桌面版弹「pi-web 服务已停止响应」→ 点「重启服务」后应用自己起在 30241 并正常，但**那个弹窗每隔几十秒又出现一次**，一直刷。

**根因**（日志可复现，同一个时间戳附近有两行几乎相同的 `端口 30141 无应答`）：
1. 监控线程在启动时把端口**捕获进闭包**（附着模式下捕获的是外部实例的 30141）。
2. 点「重启服务」→ `restart_sidecar_now` 把全局标记复位 → 新起了一个盯 30241 的线程，**但旧线程没人停**，它继续每轮探测已经死掉的 30141 → 反复告警。
3. 告警没有去重，一次故障会每个周期弹一次。

**修复**：
- 监控改成**全局唯一**线程（`start_health_monitor` 只在 setup 调一次），每轮**重新读当前端口 + 当前模式**，而不是捕获；
- 一次故障只告警一次（`alerted` / `alerted_port`），探活恢复后才重新武装；
- `Mode::Starting`（重启中）和 `Mode::Failed` 期间跳过探测，杜绝"重启被误判成挂掉"；
- 文案区分场景：附着模式→「启动服务」（起自己的实例），自起模式→「重启服务」；
- 加测试开关：`PIWEB_HEALTH_INTERVAL_MS`（默认 10000）、`PIWEB_HEALTH_HEADLESS=1`（不弹窗、自动重启，用于自动化验证）。

**验证（headless，间隔 2s）**：
```
attached 30141 → 杀掉外部实例 → 无应答×3 → [failed]×1 → 自动起 30241 → ready 4.7s → 之后 40s 内无二次告警
计数：无应答行 3，failed 行 1，30241 监听正常
```

## 回归修复二（2026-11-01 夜，用户测试会话反馈）

**症状**：在桌面版的 pi 会话里，agent 报告 `mnemon` CLI `command not found`（`~/.mnemon` 数据在、但 CLI 不在 PATH）。

**根因**：`mnemon` 装在 nvm 的 node bin 里（`~/.nvm/versions/node/v24.14.0/bin/mnemon`），只有交互式 shell 的 `.zshrc` 才会把那个目录加进 PATH。而桌面版从 Finder 启动时继承的是 `/usr/bin:/bin:/usr/sbin:/sbin`，我之前手写的 PATH 白名单只补了 `.local/bin`、homebrew 等，**漏了所有版本管理器目录**。

顺带澄清：那条回复里"没有 mnemon_recall / mnemon_remember 工具"是另一回事——`~/.pi/agent/extensions/mnemon.ts` 这个 pi 扩展本来就只注入提示/guide/状态，不注册工具，与 PATH 无关。

**修复**（`src-tauri/src/sidecar.rs`）：
1. 侧车 PATH 现在 = 登录 shell PATH（缓存/后台探测）→ 常见目录兜底 → 继承值 → 包内 runtime（放最后，保证会话里的 `node` 和你终端一致）。
2. 兜底目录覆盖 nvm（按 `~/.nvm/alias/default` 优先，其余版本从新到旧）、volta/asdf/mise/fnm/nodenv、`Library/pnpm`、deno、go、conda、orbstack、x-cmd、mimocode/codebuddy/minimax/kimi/opencode/mavis、flutter、dotnet。
3. `zsh -lic` 探测后台跑（GUI 里实测 0.9–1.2s，偶发 >2s 卡住），成功写 `login-path.txt` 缓存（7 天）；启动不阻塞。
4. 日志打出 PATH 项数、来源、是否含 nvm/mnemon。

**验证**（读侧车进程真实环境，与终端逐条对照）：

| 命令 | 侧车（第二次启动，走缓存） | 终端（`zsh -lic`） |
|---|---|---|
| node | `~/.local/bin/node` | `~/.local/bin/node` ✅ |
| pnpm | `~/.nvm/versions/node/v24.14.0/bin/pnpm` | 同 ✅ |
| mnemon | `~/.nvm/versions/node/v24.14.0/bin/mnemon`（`--version` = 0.2.13） | 同 ✅ |
| git / python3 / go / deno | homebrew / homebrew / `/usr/local/go/bin` / `~/.deno/bin` | 全同 ✅ |

PATH 项数：终端 50 → 侧车 49（差的一项是 `~/.lon/bin` 之类非目录项被去重）。
